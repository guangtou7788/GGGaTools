GGGaTools 0.3.1 — 消息路径诊断

从 GitHub Actions 下载 GGGaTools-iOS-arm64，解压取得 GGGaTools.dylib。用 ESign 注入 IPA 测试副本并重签安装。

固定文字：【GGGaTools测试】这是一条插件直接发送的测试消息

测试顺序：
1. 在自己的测试会话手动发送一条普通文字和一张可重复发送的测试图片，用于捕获当前会话参数。
2. 点黄色“测试”悬窗 → 路径诊断，查看发送入口的命中次数和筛选原因。
3. 点“直接发文字”，核对二次确认内容后尝试发送；查看聊天页和对方设备。
4. 点“复用图片直发”，核对后尝试再次发送刚才的图片；查看聊天页和对方设备。
5. 让对方发来一条新文字，查看“路径诊断”的接收计数，再点“最近捕获文字”。
6. 切换会话前点“清除校准”，避免沿用旧参数。

两个直发按钮调用消息 SDK，不触碰聊天输入框。提示“已调用”不代表服务端成功。图片只复用已上传媒体，不负责上传新图片。

“最近捕获文字”仅观察一个候选接收路径，可能未捕获或来自其他会话。现阶段不能据此自动回复。
