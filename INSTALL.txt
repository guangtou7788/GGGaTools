GGGaTools 0.2.0 — Flutter 聊天输入框测试

编译：将本目录内容放在 GitHub 仓库根目录；Actions → Build GGGaTools → 下载 GGGaTools-iOS-arm64 → 解压得到 GGGaTools.dylib。

ESign：导入动态库和目标 IPA 的测试副本，在签名设置里选择注入 GGGaTools.dylib，然后重签安装。只导入文件列表不等于注入成功。原始 IPA 请另行保存。

操作：进入自己的测试聊天 → 点击聊天输入框使键盘出现 → 确认输入框为空 → 点击黄色“填入”按钮。它只写入固定测试文本，不会发送。确认聊天对象和内容后，手动点击闲鱼的发送按钮。

成功标准：按钮出现并可拖动；固定文字进入原生聊天输入位置；手动发送成功；已有草稿不会被覆盖；无焦点时显示提示。

若按钮不显示：确认动态库确实被注入并重签，完全退出 App 后再启动。
若点击后提示未找到输入框：保持聊天页键盘打开，截图提示与输入框状态；可能是当前闲鱼版本采用不同输入视图。
若文本出现但不能发送：说明输入和提交路径不同，记录画面供后续分析。
若出现闪退：先用不含 GGGaTools 的同源 IPA 重签安装对照，保存崩溃日志和 iOS 版本。

当前版本不会自动发送消息、访问网络、读取剪贴板或自动回复。
